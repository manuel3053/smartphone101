# smartphone101

Corso super basilare sugli smartphone, al fine di insegnarne l'utilizzo anche alle persone meno esperte.

Argomenti trattati:

- Telefono: componenti hardware
- Utilizzo del telefono
  - Panoramica delle applicazioni più comuni, dal browser ai social, da cloud drive alle mail (+ installazione)
  - Sicurezza in:
    - Account, password (password manager, 2FA)
    - Mail, messaggi, chiamate
    - Browser, app
- Computer
  - Componenti hardware
  - Sistemi operativi
  - Linee guide agli acquisti
  - Revitalizzazione di un vecchio PC
- Utilizzo del computer
  - Browser + motori di ricerca
  - Programmi d'uso comune
  - Formati dei file + programmi associati
